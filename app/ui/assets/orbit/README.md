# Ícones do orbit (lados do botão "Analisar PC")

Coloque PNG ou SVG aqui para personalizar os 4 marcadores em volta do
botão central. Os arquivos são carregados automaticamente — basta
nomear conforme a posição:

| Arquivo            | Posição          | Estágio do scan         |
| ------------------ | ---------------- | ----------------------- |
| `system.png`       | topo             | Sistema                 |
| `hardware.png`     | direita          | Hardware                |
| `bios.png`         | base             | BIOS / UEFI             |
| `updates.png`      | esquerda         | Atualizações / drivers  |

Resolução recomendada: **44×44 pixels**, fundo transparente.
Formato aceito: `.png`, `.svg`, `.jpg`.

Se o arquivo não existir, o marcador usa o emoji default
(🖥 / 🧬 / 🎛 / ⬇).
